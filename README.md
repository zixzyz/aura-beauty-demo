# AURA — демо-лендинг клиники косметологии

Одностраничный сайт для клиники эстетической косметологии. Сделан по мотивам
[inlovebeauty.ru](https://inlovebeauty.ru/), в собственной молочно-голубой палитре.

Демо-версия: тексты, цены, адрес, телефон и отзывы приведены для примера.
Фотографии взяты с Pexels и также являются временными.

## Как открыть

Самый простой способ — открыть `index.html` двойным кликом. Все картинки лежат
локально, поэтому сайт работает и без сервера.

Если нужен локальный сервер:

```bash
python -m http.server 8080
```

и затем `http://localhost:8080`.

## Структура

```
index.html              — лендинг
privacy.html            — политика конфиденциальности (демо-текст)
assets/
  css/style.css         — все стили, адаптив, анимации
  js/main.js            — меню, модальное окно записи, маска телефона, Telegram
  favicon.svg
  images/               — фотографии для секций
```

## Запись и Telegram

Это демо без backend. Форма ничего не отправляет на сервер: после заполнения она
формирует готовое сообщение и показывает кнопку **«Отправить в Telegram»**.
По клику открывается чат с уже подставленным текстом заявки (имя, телефон,
услуга, удобное время). Пользователь сам отправляет сообщение администратору.

Чтобы поменять Telegram-аккаунт:

1. В `index.html` найдите у `<body>` атрибут
   `data-telegram="https://t.me/aura_beauty_demo"` и укажите свою ссылку.
2. `assets/js/main.js` при загрузке подставит эту ссылку во все кнопки Telegram.
3. Для случая отключённого JavaScript желательно также заменить статические
   ссылки `https://t.me/aura_beauty_demo` в `index.html`
   (поиск по `aura_beauty_demo`).

Если нужны автоматические заявки без Telegram, есть варианты:

- Telegram Bot API + небольшой serverless-обработчик (Vercel / Netlify Functions);
- онлайн-запись через YCLIENTS или Dikidi (кнопки ведут на виджет);
- сервисы форм: Formspree, Getform, Web3Forms — подключаются без своего сервера.

## Что можно быстро заменить

- **Название, телефон, адрес** — поиском по `AURA`, `+7 (999) 123-45-67`,
  `Пречистенка`.
- **Цены и услуги** — секции `#services` и `#offers` в `index.html`.
- **Специалисты** — карточки в `#team`, фотографии в `assets/images/team-*.jpg`.
- **Отзывы** — карточки в `#reviews`.
- **Фотографии** — просто положите свои файлы в `assets/images/` с теми же именами
  или обновите пути в HTML. Для карточек лучше вертикальные кадры 4:5.
- **Палитра и шрифты** — переменные в начале `assets/css/style.css`:
  `--milk`, `--ink`, `--ink-deep`, `--blue` и т. д.

## Палитра

| Переменная | Значение | Назначение |
|---|---|---|
| `--milk` | `#f7f3ed` | молочный фон |
| `--milk-2` | `#f1ebe2` | тёплые секции |
| `--ink` | `#40607d` | основной нежно-голубой текст |
| `--ink-deep` | `#2c4a63` | заголовки и кнопки |
| `--blue` | `#6e8fae` | акцент, курсивные акценты |

Шрифты: **Cormorant Garamond** (заголовки) и **Manrope** (текст), подключены
через Google Fonts. При отсутствии интернета сработают системные запасные
шрифты.

## Важно перед публикацией

- Заменить демо-контакты, цены, отзывы и фотографии на реальные.
- Проверить медицинские формулировки и добавить обязательную информацию
  о лицензии и противопоказаниях.
- Заменить демо-политику конфиденциальности на утверждённый юристом документ.
- Подключить реальную отправку заявок и аналитику (Яндекс Метрика / GA4).
- Убрать плашку «Демо-версия» в футере.
