# AURA — демо-сайт клиники косметологии

- **Опубликованный сайт:** https://zixzyz.github.io/aura-beauty-demo/
- **Онлайн-запись:** https://zixzyz.github.io/aura-beauty-demo/booking.html
- **Репозиторий:** https://github.com/zixzyz/aura-beauty-demo

Две страницы: лендинг и отдельная онлайн-запись в три шага
(услуги → дата и время → контакты). Стиль — строгий редакционный: матча,
коричневый, кремовый и карамельный; крупная типографика без курсива,
тонкие линии и квадратные формы. Ориентиры: inlovebeauty.ru и patibeauty.ru,
логика записи — как в YCLIENTS.

Демо-версия: тексты, цены, адрес, телефон и отзывы приведены для примера.
Фотографии взяты с Pexels и являются временными.

## Как открыть

Онлайн-версия уже доступна: https://zixzyz.github.io/aura-beauty-demo/

Локально проще всего открыть `index.html` двойным кликом. Все картинки и шрифт
Prata лежат локально. Для формы записи нужен JavaScript.

Если нужен локальный сервер:

```bash
python -m http.server 8080
```

и затем `http://localhost:8080`.

## Деплой

Сайт размещён на бесплатном GitHub Pages из ветки `main` (корень репозитория).
После изменений:

```bash
git add -A
git commit -m "update site"
git push
```

GitHub Pages пересоберёт сайт автоматически через 30–60 секунд.

## Структура

```
index.html              — лендинг
booking.html            — онлайн-запись: услуги, время, контакты
privacy.html            — политика конфиденциальности (демо-текст)
assets/
  css/style.css         — стили лендинга, записи и адаптив
  js/main.js            — меню, анимации появления, скроллспай, Telegram
  js/booking.js         — выбор услуг, даты, времени, валидация и заявка
  fonts/Prata-Regular.ttf
  images/               — фотографии для секций
  og-image-2026.jpg     — превью для Telegram и соцсетей
```

## Онлайн-запись

`booking.html` работает без backend, как демо:

1. **Услуги.** Можно выбрать несколько услуг, фильтр по категориям,
   справа (на мобильном — внизу) считается итог.
2. **Время.** Специалист, дата на две недели, свободные слоты.
3. **Контакты.** Имя, телефон, комментарий и согласие.
4. **Готово.** Заявка собирается в текст и открывается в Telegram с уже
   заполненным сообщением. Пользователь сам отправляет его администратору.

Ссылки с лендинга передают параметры: `booking.html?service=laser` и
`booking.html?specialist=anna`. Так предзаполняются услуга или специалист.

Чтобы поменять Telegram-аккаунт:

1. В `index.html` и `booking.html` у `<body>` найдите
   `data-telegram="https://t.me/aura_beauty_demo"` и укажите свою ссылку.
2. `assets/js/main.js` подставит её во все Telegram-кнопки.
3. Для случая отключённого JavaScript также замените статические ссылки
   `https://t.me/aura_beauty_demo` поиском по репозиторию.

Если нужны автоматические заявки без Telegram:

- Telegram Bot API + serverless-обработчик (Vercel / Netlify Functions);
- онлайн-запись через YCLIENTS или Dikidi (кнопки ведут на виджет);
- сервисы форм: Formspree, Getform, Web3Forms.

## Что заменить

- **Название, телефон, адрес** — поиском по `AURA`, `+7 (999) 123-45-67`,
  `Пречистенка`.
- **Услуги и цены на лендинге** — секции `#services` и `#offers` в `index.html`.
- **Услуги в записи** — массив `services` в `assets/js/booking.js`
  (название, цена, длительность, категория).
- **Специалисты** — карточки в `#team` (`index.html`) и массив `specialists`
  в `booking.js`.
- **Отзывы** — карточки в `#reviews`.
- **Фотографии** — свои файлы в `assets/images/` с теми же именами.
- **Палитра** — переменные в начале `assets/css/style.css`.
- **Превью для Telegram** — заново собрать `assets/og-image-2026.jpg` после смены
  бренда или фото.

## Палитра

| Переменная | Значение | Назначение |
|---|---|---|
| `--cream` | `#f2ebde` | основной кремовый фон |
| `--cream-2` | `#e9dfcf` | тёмные кремовые секции |
| `--paper` | `#fbf7f0` | карточки и панели |
| `--brown` | `#3f3026` | текст, тёмные блоки |
| `--brown-soft` | `#6b5748` | вторичный текст |
| `--matcha-deep` | `#4e5a43` | кнопки и акцентные блоки |
| `--matcha` | `#859274` | декоративные линии |
| `--caramel` | `#bb8458` | карамельные акценты |
| `--caramel-ink` | `#8f5b36` | мелкие акцентные подписи |

Шрифты: **Prata** (заголовки, локальный файл, без курсива) и **Manrope**
(интерфейс и текст, Google Fonts). При отсутствии интернета Manrope
заменится системным шрифтом.

## Важно перед публикацией

- Заменить демо-контакты, цены, отзывы и фотографии на реальные.
- Проверить медицинские формулировки и добавить обязательную информацию
  о лицензии и противопоказаниях.
- Заменить демо-политику конфиденциальности на утверждённый юристом документ.
- Подключить реальную отправку заявок и аналитику (Яндекс Метрика / GA4).
- Убрать плашку «Демо-версия» в футере.
- Проверить, что свободные слоты в демо-записи соответствуют реальному расписанию.
